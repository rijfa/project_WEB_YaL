# 🧠 Neural Visualizer

**Neural Visualizer** — это высокотехнологичный веб-сервис для распознавания рукописных цифр в реальном времени. Проект объединяет современный веб-дизайн в стиле **Glassmorphism** и производительный инференс нейронных сетей.

---

## 🚀 Основные возможности
* **Interactive Canvas:** Рисование цифр на холсте с поддержкой Touch-событий.
* **AI Engine:** Использование сверточной нейросети (CNN) через среду **ONNX Runtime**.
* **Real-time Stats:** Расчет уверенности модели в процентах (Softmax).
* **User History:** Сохранение истории распознаваний в базу данных с мгновенным отображением в ленте.
* **Security:** Полноценная авторизация с хешированием паролей.

---

## 📋 Техническое задание (ТЗ)

### 1. Цель проекта
Создание программного комплекса для интерактивной демонстрации работы моделей глубокого обучения через веб-интерфейс.

### 2. Технический стек
* **Backend:** Python 3.12, Flask, SQLAlchemy.
* **ML Инференс:** ONNX Runtime, NumPy, Pillow.
* **Database:** SQLite.
* **Frontend:** HTML5 Canvas, CSS3 (Glassmorphism), JavaScript (Fetch API).

### 3. Функциональные требования
1. **Предобработка:** Автоматический ресайз до $28 \times 28$ px и нормализация входного тензора.
2. **Распознавание:** Классификация цифр 0–9 с выводом вероятности.
3. **История:** Хранение логов распознавания (изображение + результат) для каждого пользователя.
4. **UX:** Динамическая подгрузка новых результатов в ленту истории без обновления страницы.

### 2. Технический стек
* **Backend Core:** * `Python 3.12` — основной язык разработки.
    * `Flask` — WSGI веб-фреймворк для реализации REST API.
    * `Flask-Login` — управление сессиями и аутентификацией.
* **Machine Learning & Data Science:**
    * `ONNX Runtime` — кроссплатформенный движок для инференса нейросети.
    * `NumPy` — матричные вычисления и преобразование тензоров.
    * `Pillow (PIL)` — обработка и нормализация растровых изображений.
* **Database & Storage:**
    * `SQLite` — легковесная реляционная база данных.
    * `SQLAlchemy` — ORM для абстракции запросов к БД.
* **Frontend:**
    * `HTML5 / CSS3` — современная верстка с применением Glassmorphism эффектов.
    * `JavaScript (ES6+)` — асинхронное взаимодействие через Fetch API.

### 3. Функциональные требования
1.  **Модуль аутентификации:**
    * Регистрация новых пользователей и безопасный вход в систему.
    * Хеширование паролей на стороне сервера (алгоритм PBKDF2).
2.  **Интерактивный холст:**
    * Отрисовка в реальном времени с поддержкой Mouse и Touch событий.
    * Механизм очистки холста и захвата изображения в формат `base64`.
3.  **Интеллектуальная обработка:**
    * Масштабирование изображения до $28 \times 28$ пикселей и инверсия цветов.
    * Нормализация входного вектора (Mean/Std) для соответствия датасету MNIST.
    * Классификация с выводом топ-1 результата и расчетом вероятности через Softmax.
4.  **Система логирования и истории:**
    * Автоматическое сохранение каждого распознавания в базу данных.
    * Отображение персональной истории запросов для авторизованных пользователей.
    * Динамический рендеринг новых записей без перезагрузки страницы.

### 4. Структура проекта
* `app.py` — главный файл приложения; содержит маршруты (routes) и логику API.
* `models.py` — описание схемы базы данных (классы User и Drawing).
* `model.onnx` — сериализованная весовая модель нейронной сети.
* `static/` — директория со статическими ресурсами:
    * `style.css` — описание визуальных стилей и анимаций.
    * `uploads/` — хранилище сгенерированных пользовательских рисунков.
* `templates/` — набор Jinja2-шаблонов:
    * `index.html` — основная рабочая область с холстом и историей.
    * `login.html` / `register.html` — формы входа и регистрации.
* `requirements.txt` — список зависимостей для быстрого развертывания проекта.
